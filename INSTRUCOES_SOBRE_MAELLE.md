# Sobre a Maelle — novo layout

- `sobre.html` foi redesenhado com as seções A Marca, Visão, Valores e Como Trabalhamos.
- A seção Quem está por trás foi excluída.
- A página continua a consultar `/api/institutional-page?page=sobre` para conteúdo editado pelo Painel ADM.
- No Painel ADM, edite os três blocos na ordem: Visão, Valores, Como Trabalhamos. Para Valores, use uma linha por item no formato `Título|Descrição`. Separe parágrafos com uma linha em branco.
- ATENÇÃO: se já houver conteúdo salvo para `sobre` no Supabase, ele prevalece sobre o texto padrão novo. Atualize-o no Painel ADM para usar os novos textos.
- Verifique a imagem da seção Visão: o arquivo de imagem pode precisar ser trocado pela foto de modelo desejada.
- Os textos sobre fornecedores e práticas devem ser confirmados pela empresa antes de publicar como alegações factuais.
- O checkout SumUp e as APIs de pagamento não foram alterados.
