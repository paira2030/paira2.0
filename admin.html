Pagamentos

Viva.com API

Integração pendente de backend seguro. Este projeto é estático. As credenciais Client Secret e os tokens de acesso nunca devem ser guardados no navegador. A aba abaixo guarda apenas preferências não secretas neste computador; não ativa cobranças.

Para ativar a Viva.com é necessário criar endpoints de servidor para autenticação, criação de ordens, webhooks verificados e consulta de transações. Configure Client ID e Client Secret exclusivamente como variáveis de ambiente no servidor.
